# 茅洲河中游 · 空间结构：PPT → HTML 测试

双击 `index.html`（或直接双击 `static.html` / `map.html`）就能打开，无需安装、无需构建。建议用 Chrome 或 Edge。

| 文件 | 说明 |
|---|---|
| `static.html` | **静态复刻**：Illustrator SVG 清理后内嵌为网页，与导出 PNG 基本一致。加 `#export` 会按原画板尺寸（2156×1390）输出 |
| `map.html` | **交互地图**：MapLibre GL（与 Mapbox GL 同一套 API，不需要 token）。设计图层已配准到真实经纬度，可缩放平移，有图层开关、透明度和底图切换 |
| `assets/basemap.jpg` | 原 AI 文件里的栅格底图（已裁到画板范围） |
| `data/design-data.js` | 设计图层（WGS84 经纬度，矢量）+ 标注 + 配准后的原底图，由脚本生成 |
| `data/design-layers.geojson` | 同一套图层的 GeoJSON，可直接拖进 QGIS / ArcGIS / Mapbox Studio |
| `data/georef-report.json` | 配准参数、控制点和误差 |
| `lib/` | 本地打包的 maplibre-gl 5.24.0，断网也能用，不依赖 CDN |
| `js/config.js` | **底图 / Mapbox 配置只需改这个文件** |
| `screenshots/` | 测试截图 |

## 交互地图怎么用
- 左上角面板：打开或关闭设计图层（片区、中央家园斜线、水系、联系弧线、圈层、点阵光晕、半调网点、标注），调整整体透明度，切换底图。
- 「回到原图视角」：回到和原图一致的取景。
- 「原设计底图（对位校核）」/「OSM 真实水系（对位校核）」：用来检查设计图和真实地理是否对得上，默认关闭。
- 网址参数（方便截图或分享）：`map.html?basemap=amap-dark&view=113.79,22.776,14&on=check&off=halftone&nopanel`

**GCJ-02 自动纠偏**：高德等国内地图使用国测局坐标，在深圳和 WGS84 相差约 500 m。切到高德底图时，页面会自动把设计图层转换成 GCJ-02，所以对位始终是对的。

**国内网络**：如果 OpenFreeMap 6 秒内加载不出来，或瓦片连续报错，页面会自动切到「高德 暗色」并给出提示。

### 换成 Mapbox
1. 打开 `js/config.js`，在 `mapbox.token` 里填上你的 public token（`pk.` 开头）；`style` 填 `用户名/样式ID`，比如 `mapbox/dark-v11`，或者你在 Mapbox Studio 里做的样式。
2. 刷新页面，底图列表最上面会出现 “Mapbox · …”。这一项走的是 Mapbox 栅格瓦片接口，不用改其他代码。
3. 如果要用 Mapbox 矢量样式，把 `lib/maplibre-gl.js/css` 换成 `mapbox-gl.js/css`，再把 `maplibregl.` 改成 `mapboxgl.` 并设置 `mapboxgl.accessToken`。两者 API 基本一致。
4. 用 Mapbox 中国（mapbox.cn）的样式时，把 `crs` 改成 `'gcj02'`。

## 配准方法（SVG 坐标 → 经纬度）
1. 从 OpenFreeMap 矢量瓦片（z14，OSM 数据）取出水体面和河道线。Overpass 从本机访问不了，所以改用这个数据源。
2. 把 AI 文件里的栅格底图提取成水体掩膜，用 ECC 图像配准（仿射）做粗配，再对 290 个局部窗口逐一匹配，用这些对应点拟合 **三次多项式**（SVG 单位 → Web Mercator）。之所以用三次多项式而不是仿射：交叉验证误差中位数从 101 m 降到 42 m，说明原底图本身带有非线性变形（推测是多张截图拼接的结果）。
3. 设计图层里的每个顶点都按这个变换转成经纬度，所以任何缩放级别下都是矢量、都清晰。
4. 比例尺：约 13.0 m / SVG 单位，画板约 28 × 18 km。

**误差（相对 OSM）**
- 全图 197 个局部窗口的残差：中位数 35 m，平均 55 m，P90 127 m。
- 控制点：茅洲河入海口 30 m；燕川段 S 形弯 13 m；沙井河汇入口 29 m；楼村—光明段河弯 23 m；塘下涌—洋涌段 16 m；沙井海岸线 15 m；石岩水库 70 m；上游东转南拐点 112 m（该处匹配质量低）；交椅湾海岸 125 m。
- 设计图中的茅洲河/沙井河 vs OSM 河道中心线：在设计画到的范围内，78% 的中心线点落在设计河道面之内，90% 在 100 m 以内。
- 原图右下角的大湖经核对是 **石岩水库（石岩湖）**，不是公明水库/光明湖；光明湖在画板右缘之外。设计图里湖的轮廓画得比 OSM 大（4.4 km² 对 2.1 km²），质心相差约 180 m。中部的三个小湖（长流陂水库一带）质心相差约 150 m。这些差异主要来自手绘轮廓，不是配准误差。

## 已知差异和限制
- **SVG 和 PNG 不是同一个版本**。PNG 里是「中央家园 / CENREAL LIVING DISTRICT」，SVG 里还是旧的「潭头-后亭 / Tantou-Houting」；PNG 中新桥东标注的位置挪过，水系压在片区上面，沙井河、茅洲河、海洋新城的标注是粗体。静态页已经按 PNG 改过来。注意 “CENREAL” 是原 PNG 里的拼写错误（应为 CENTRAL），这里照原样保留了，需要的话改一个词就行。
- 字体：Windows 上会直接用微软雅黑；其他系统依次回退到苹方、思源黑体/Noto。在测试机（Noto Sans CJK）上，文字字形和字宽和 PNG 略有差别，这是剩余差异的主要来源（像素平均差 4.2/255，SSIM 0.93）。
- 交互地图里，图案（半调网点、点阵、斜线）都转成了真实几何，所以和地图一起缩放；放大后网点会逐级淡化。渐变（海域、联系弧线）用 28–40 条色带近似，放大后能看到很细的色阶。
- 标注是 HTML 叠加层（矢量文字），会跟随缩放，但大小限制在可读范围内；缩得很小时会隐藏英文小字。
- 高德卫星瓦片从海外测试机并发请求时会被限流，小窗口下测试正常，国内访问应该没有问题。
